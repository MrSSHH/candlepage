How to read PDFs in dark mode in Chrome, without turning the pictures into negatives

Reading a white PDF at night hurts. Most dark mode tools fix it by inverting every pixel, which also ruins photos, charts and book covers. Here is how to get a dark page and keep the pictures real.

  1. Install Candlepage

    Add the free extension from the Chrome Web Store. It also works in Microsoft Edge.

  2. Open any PDF

    Click a PDF link on a website and it opens in the dark viewer. On a page with several PDFs, the extension window lists them all and can highlight the link for you.

  3. Choose how pictures look

    Off darkens everything, so photos look like negatives. Auto keeps photos in colour and darkens screenshots of light app windows. All shows every picture exactly as printed. You can change this any time from the brightness button or the right-click menu.

  4. Dark mode for PDFs on your computer

    Chrome blocks extensions from local files by default. Open chrome://extensions, click Details on Candlepage and turn on Allow access to file URLs. Candlepage guides you through this the first time.

  5. Scanned books

    A scan is only pictures of pages, so the page numbers and chapters are missing. Candlepage can read them with OCR on your computer, including roman numerals (i, ii, iii) in the front matter. Nothing is uploaded, and it asks before it starts.
